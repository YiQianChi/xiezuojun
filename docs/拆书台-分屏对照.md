# 拆书台 · 分屏对照 — 功能细节（v1，2026-11-10 与 Boss 对齐方向；P0 已实现并部署 180 验收通过）

> 方案拍板：拆书产出进编辑器走**分屏对照**——复用现有 SplitEditor，新增一类只读内容源「拆书原文」。
> Demo：web/sketches/008-chaishu/（8899 /xzj-sketches/008-chaishu/?v=4，写作菌真实样式版）。

## 一句话

作者把自己想学的书拆了（五件套产出），在**现有分屏**里左屏只读看原文、右屏写自己的章节，划词收藏进灵感库喂 AI。

## 现有基建（全部复用，不重做）

| 现有能力 | 位置 | 怎么用 |
|---|---|---|
| 分屏面板（⇉左右/⇅上下、拖宽、点击互换、手机上下抽屉） | `SplitEditor.vue` | 原样使用，只是多打开一种东西 |
| 翻章 ‹ › / 拖章到分屏 / 页头标题 | SplitEditor `selectDoc/prevChapter/nextChapter` | 拆书原文源接同一套 |
| 只读机制（同章两边开=右侧转只读） | SplitEditor `conflict` | 拆书源恒为只读，直接复用 editable 开关 |
| 灵感库（.qn-bar 存 type=insp） | AIContextPanel + stickyApi | 不用——拆书素材独立存储，与灵感库隔离 |
| 纸张/章名头/主题 token | editor-page.css | 拆书原文渲染同款纸面 |

## 新增的东西（就三块）

### 1. 拆书库（后端为主）

**入口**：编辑器顶栏 ⋯ 菜单加「拆书库」→ 弹层（不动左树，不占右栏页签）。

**数据流**：
```
上传 txt/epub（≤30MB）
→ 后端分章（沿用导出的章节正则思路，识别失败给手动分隔符输入）
→ 建 dismantle 记录，状态=拆解中，逐批 AI 抽取（复用 gateway 槽位+usage_tracker 计费）
→ 产出：五件套（章节大纲/人物卡/关系网/节奏曲线/可复用套路）+ 章节级标注
→ 状态=已拆解，可查看/分屏打开
```

**存储**（MySQL 单域 5 表，sticky 同款模式——比原设想的文件引擎省事，且不进 documents 表，不会污染左树/回收站/导出）：
- `dismantle_books`（书元信息+状态+进度）/ `dismantle_chapters`（原文分章 mediumtext）
- `dismantle_outputs`（五件套 markdown，book+kind 唯一）/ `dismantle_annotations`（章节级标注）
- `dismantle_clippings`（划词素材，跨书汇总在拆书库弹层「素材」页签）

**模型**：env `DISMANTLE_MODEL`（缺省走 MEMORY_MODEL→AI_MODEL→MiniMax-M3 链）。⚠️ 智能体套餐 key 不支持 MiniMax-M3（404 UnsupportedModel），180 已设 `DISMANTLE_MODEL=doubao-seed-2-0-mini-260428` 实测可用。

**限制**：每项目 ≤5 本；单本 ≤300 万字；拆解失败可重试（断点续拆=按章记录已完成）。

### 2. 分屏只读源（前端为主）

SplitEditor 的选中状态从 `selectedId: number` 扩成联合：
```ts
{ kind: 'doc', id: number }                       // 现有：本项目章节
{ kind: 'split-book', bookId, chapterIdx }        // 新增：拆书原文
```

行为细节：
- 页头标题：`《长夜余晖》· 第3章 灯油` + 金色「只读」小标（同款 pill，不用 emoji）
- ‹ › 在该书的章节间翻；书切换 = 页头书名处小下拉（不新增常驻 UI）
- 恒 `setEditable(false)`；状态栏位置显示 `拆书 · 2,140 字`（无保存/字数编辑态）
- conflict 逻辑不适用（永远不会和左侧同章）；localStorage 草稿键不启用
- 离线：当前章缓存 `localStorage xzj-dismantle-:bookId-:idx`（同 doc-content 模式）
- 章名头：拆书章节有原文自带标题的用原文标题，不套本书章号规则
- 手机：上下抽屉里同样只读可滚，‹ › 保留

**章节标注联动**（P1，可后做）：分屏页头「标注」开关，当前章有标注时在正文下方列出（kind 标签：钩子/手法/意象），点击标注滚到对应段落（拆解时记段落序号）。

### 3. 划词收藏 → 灵感库

- 在拆书原文里选中文字 → 浮出「收藏」钮（桌面 mouseup 检测，位置同 demo）
- 存入**拆书素材列表**（独立存储，见下），带来源 `《书名》·第N章`
- 素材留在拆书域：可查看/复制/删除/「引用到 AI 对话」（一次性附加，不持久点亮、不进设定/灵感）
- **红线：拆书产出永不写入用户创作域**——不进记忆、不进故事线、不进设定、不进灵感库。用户要用，自己复制粘贴；AI 引用必须显式点按钮、单次生效
- 手机端：选中靠系统菜单，浮钮改为选中后页头出现「收藏选中」按钮（P1）
